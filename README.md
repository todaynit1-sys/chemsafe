### 수정하는 법
- **디자인·색·간격** → `assets/style.css` 하나만 고치면 전 페이지에 반영됩니다.
- **내용** → 해당 HTML 파일을 직접 고치면 됩니다.
- **메뉴·푸터** → 각 HTML 파일에 같은 마크업이 들어 있으므로 7개 파일을 함께 고쳐야 합니다.

> ⚠️ `_build.py` 는 이 파일들을 처음 만들 때 쓴 생성기입니다.
> HTML을 직접 수정한 뒤에 다시 실행하면 수정분이 전부 덮어써집니다. 다시 실행하지 마세요.
> (필요 없으면 삭제해도 사이트 동작에는 아무 영향이 없습니다.)

## 로고 — 벡터(SVG)로 전환
### 왜 래스터로는 안 됐나
로고 락업이 가로 4.4:1이라 헤더 높이(30~46px)에 맞추면 한글이 14~20px가 됩니다.
원본 90px 획을 그만큼 줄이면 얇은 선이 투명 배경과 평균화되어 색이 옅어집니다.
실측: 파일 chroma 133 → 46px 렌더 시 107. 어떤 픽셀 보정으로도 한계가 있었습니다.

### 해결 — potrace 벡터 변환
협회가 준 **단색 플랫 고해상도 파일(2176×722, `#5DA7C6`)** 을 벡터로 추적했습니다.
원본 글자 모양 그대로, 어떤 크기·배율에서도 선명하고 색이 그대로 나옵니다.

재현 절차:
1. 흰 배경 합성 역산으로 커버리지 추출 — `alpha = median((255-P)/(255-INK))`
2. 2~3배 업샘플 후 0.5 임계로 이진화. **잉크를 검정으로** 저장할 것 (potrace는 검정을 추적)
3. `potrace x.pbm -s -o x.svg --turdsize 2 --alphamax 1.0 --opttolerance 0.2`
4. `<g>` 의 `fill` 을 원하는 색으로 교체해 색상별 파일 생성
   (potrace 출력의 `<g>` 에 이미 `stroke="none"` 이 있으므로 속성 중복 주의 — 중복 시 SVG 파싱 실패)

### 쓰는 곳
| 파일 | 쓰는 곳 | 크기 |
|---|---|---|
| logo.svg | 헤더 | 30px / 데스크톱 46px |
| logo-light.svg | 메인 KV, 푸터 | KV 46/70px, 푸터 40/34px |
| mark.svg / mark-light.svg | 섹션 제목 아이콘 | 16px |
| icon.svg | 진입 게이트 아이콘 | 31/36px |
| mark-white.svg | 배경 워터마크 | opacity 5~13% |

색을 바꾸려면 해당 SVG 파일의 `fill="..."` 한 곳만 고치면 됩니다.

## KV 이미지 처리 방식
협회가 제공한 배너에는 로고와 슬로건이 이미지에 인쇄되어 있어, 그대로 쓰면 모바일에서 잘리거나 글자가 뭉갭니다.
그래서 **문구가 없는 영역만 잘라 배경으로 쓰고, 로고·슬로건은 HTML 텍스트로 다시 올렸습니다.**
- 데스크톱 → 배너 하단 스카이라인 파노라마 (문구 없음)
- 모바일 → 배너 좌측 도시·분자망 세로 영역 (문구 없음)
- 화면 폭에 따라 CSS가 배경을 자동으로 바꿉니다 (art direction)
어떤 폭에서도 글자가 선명하고, 배너의 분위기는 그대로 유지됩니다.

## 메인 모션그래픽 (index.html)
외부 라이브러리 없이 SVG + CSS + 순수 JS로 만들었습니다. 영상 파일이 아니라서 가볍고, 어떤 화면 크기에서도 선명합니다.

### ① 첫 화면 — 자동재생 모션 필름 (약 30초 반복)
아이소메트릭 사업장 일러스트 위에서 7개 장면이 영상처럼 이어집니다.
| 장면 | 연출 | 자막 |
|---|---|---|
| 01 사업장 | 선이 그려지며 사업장 등장 | 화학물질을 취급하는 사업장 |
| 02 위험 | 저장탱크에서 영향 범위가 퍼지고 인근 마을이 경고색 | 사고는 사업장 밖까지 번질 수 있습니다 |
| 03 진단 | 스캔 빔이 지나가며 설비마다 체크 표시 | 잠재된 유해·위험 요인을 진단합니다 |
| 04 계획·인허가 | 서류가 떠오르고 도장 | 법정 서류와 인허가를 지원합니다 |
| 05 교육 | 교육장 앞에 교육생 등장 | 현장의 사람을 교육합니다 |
| 06 AI 전환 | 설비를 잇는 AI 연결망 (민트) | 규제 대응 업무의 AI 전환을 지원합니다 |
| 07 함께 | 사업장을 감싸는 보호 돔 + 로고 | 한국화학안전협회가 함께 하겠습니다 |
- 하단 막대를 누르면 해당 장면으로 이동, 오른쪽 버튼으로 일시정지
- 화면 밖으로 나가거나 다른 탭으로 가면 자동으로 멈춤 (배터리·성능)
- 자막·시간은 `assets/motion.js` 의 `SC` 배열에서 고칩니다

### ② 업무 스크롤 스토리 — "협회가 하는 일"
화면을 내리면 같은 사업장 일러스트가 고정된 채 단계별로 바뀝니다.
01 화학사고예방관리계획서 → 02 PSM → 03 안전진단 → 04 통합환경 허가 → 05 인허가 종합 → 06 유해·위험방지계획서 → 07 법정 안전교육 → 08 AI특화 공동훈련센터 → 마무리
- PC: 왼쪽 무대 고정 + 오른쪽 설명 / 모바일: 위쪽 무대 고정 + 아래 설명
- 각 단계의 "자세히 보기"는 해당 상세 페이지로 이동 (주요 사업은 해당 항목 아코디언이 열린 채로 이동)
- 문구는 `index.html` 의 `.story__steps` 안에서 직접 고치면 됩니다. 모든 문구는 기존 상세 페이지에 있는 내용만 사용했습니다

### ③ AI특화 공동훈련센터 섹션 (스토리 다음)
민트 톤의 어두운 섹션으로 AI 교육 내용을 메인에서 바로 보여줍니다.
- 진단 → 교육 → 현장적용 → 확산 4단계: 2.8초마다 다음 단계가 켜지며 아이콘이 움직입니다 (누르거나 마우스를 올리면 해당 단계로 이동)
- 직무별 6개 과정 카드 (모바일은 옆으로 밀어 보기) → `ai-center.html#courses`
- 참여 절차 6단계, 고용보험 안내, 수강신청 · 연간 일정 · 센터 안내 버튼
- 문구는 모두 `ai-center.html` 에 있는 내용 그대로입니다. 협약 기업 수·만족도 숫자는 이전 요청대로 메인에 넣지 않았습니다

## 화면 연출 (스크롤 등장 효과)
`assets/app.js` 가 페이지 로드 시 카드·표·목록 등을 골라 `data-rv` 를 붙이고,
IntersectionObserver 로 화면에 들어올 때 위로 15px 올라오며 나타나게 합니다.
마크업에 아무 것도 적지 않아도 되고, 아래 안전장치가 걸려 있습니다.
- 접힌 아코디언(`details`) 안의 요소는 대상에서 제외 (안 열면 영원히 안 보이는 문제 방지)
- 아코디언을 열면 그 안의 요소를 즉시 표시
- 2.2초 뒤 남아 있는 요소는 강제로 표시 (관찰 실패 대비)
- `prefers-reduced-motion` 및 인쇄 시에는 효과 없이 바로 표시

그 밖의 연출: 헤더 스크롤 시 그림자, 메뉴 밑줄 애니메이션, 카드 호버 시 화살표 이동,
소식 목록 행 호버 틴트, 지표 블록 민트 바, 푸터 상단 그라데이션 라인, 섹션 키커 헤어라인.

## 검수 결과
320 / 375 / 414 / 768 / 1024 / 1280 / 1600px × 7개 페이지 전수 확인
- 가로 스크롤 0, 깨진 이미지 0, 끊긴 내부 링크 0
- 넓은 표(인허가 비교, 교육과정)는 모바일에서 좌우 스크롤 되도록 처리
- 480px 이하 전용 규칙: 본문 16.5px, 버튼 전폭, 섹션 여백 축소, 아코디언·표 패딩 축소, 하단 고정 CTA 여백 확보
- KV 높이는 `svh` 기준이라 모바일 브라우저 주소창이 접히고 펼쳐져도 튀지 않습니다
