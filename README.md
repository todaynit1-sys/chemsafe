### 수정하는 법
- **디자인·색·간격** → `assets/style.css` 하나만 고치면 전 페이지에 반영됩니다.
- **내용** → 해당 HTML 파일을 직접 고치면 됩니다.
- **메뉴·푸터** → 각 HTML 파일에 같은 마크업이 들어 있으므로 7개 파일을 함께 고쳐야 합니다.

> ⚠️ `_build.py` 는 이 파일들을 처음 만들 때 쓴 생성기입니다.
> HTML을 직접 수정한 뒤에 다시 실행하면 수정분이 전부 덮어써집니다. 다시 실행하지 마세요.
> (필요 없으면 삭제해도 사이트 동작에는 아무 영향이 없습니다.)

## 로고 체계
로고 **두 개를 용도별로 쓰지 않고**, 새 K 로고 한 벌의 형태를 나눠 씁니다.
| 형태 | 쓰는 곳 |
|---|---|
| 가로형 (심볼+국문+영문) | 데스크톱 헤더, KV, 푸터 |
| 컴팩트 (심볼+국문) | 모바일 헤더 — 작은 크기에서 영문 줄이 뭉개지는 것 방지 |
| K 심볼 단독 | 파비콘, 섹션 제목 아이콘, 진입 게이트 아이콘, 배경 워터마크 |

어두운 배경용은 흰색 실루엣이 아니라, **원본 색상을 유지한 채 밝기만 올린** 버전입니다
(심볼 +32% / 워드마크 +66%). 흰색으로 뭉개면 리본 그라데이션과 민트 점이 사라집니다.

## 폰트
- 본문 **Pretendard Variable** (jsdelivr)
- 제목 **SUIT Variable** (jsdelivr `sun-typeface/SUIT@2`)
- 로드 실패 시 시스템 한글 산세로 대체되며 레이아웃은 깨지지 않습니다.

## KV 이미지 처리 방식
협회가 제공한 배너에는 로고와 슬로건이 이미지에 인쇄되어 있어, 그대로 쓰면 모바일에서 잘리거나 글자가 뭉갭니다.
그래서 **문구가 없는 영역만 잘라 배경으로 쓰고, 로고·슬로건은 HTML 텍스트로 다시 올렸습니다.**
- 데스크톱 → 배너 하단 스카이라인 파노라마 (문구 없음)
- 모바일 → 배너 좌측 도시·분자망 세로 영역 (문구 없음)
- 화면 폭에 따라 CSS가 배경을 자동으로 바꿉니다 (art direction)
어떤 폭에서도 글자가 선명하고, 배너의 분위기는 그대로 유지됩니다.

## 어두운 배경용 로고
흰색 실루엣(`logo_full_w.png`)은 원형 심볼이 통짜로 채워져 CI 느낌이 사라집니다.
그래서 **원본 컬러 로고의 색상을 유지한 채 밝기만 올린** `logo_full_dark.png` 를 만들어 KV와 푸터에 사용합니다.
- 원형 심볼은 +30%만 밝게 → CI 시안 그라데이션과 KCSA 글자가 그대로 보입니다
- 국문·영문 워드마크는 +66% → 어두운 배경에서 읽히는 밝은 시안 톤
- 진입 게이트 아이콘은 흰 라운드 박스 + 원본 컬러 마크

## 검수 결과
320 / 375 / 414 / 768 / 1024 / 1280 / 1600px × 7개 페이지 전수 확인
- 가로 스크롤 0, 깨진 이미지 0, 끊긴 내부 링크 0
- 넓은 표(인허가 비교, 교육과정)는 모바일에서 좌우 스크롤 되도록 처리
- 480px 이하 전용 규칙: 본문 16.5px, 버튼 전폭, 섹션 여백 축소, 아코디언·표 패딩 축소, 하단 고정 CTA 여백 확보
- KV 높이는 `svh` 기준이라 모바일 브라우저 주소창이 접히고 펼쳐져도 튀지 않습니다

## GitHub Pages 배포
1. 새 저장소 생성 (Public)
2. 위 파일 전부를 저장소 루트에 업로드 후 커밋
3. Settings → Pages → Source `Deploy from a branch` → Branch `main` / `/ (root)` → Save
4. 1~2분 뒤 `https://<계정명>.github.io/<저장소명>/`

커스텀 도메인: 루트에 도메인 한 줄만 적은 `CNAME` 추가 + DNS에 CNAME → `<계정명>.github.io`
